# DIGGER — 1983 年挖金子的 C++ 复刻版

Win32 / C++17，无第三方库、无任何素材文件。整帧在软件里用抗锯齿图元画出来，
音效逐采样合成，音乐播放器也走自己的混音器。

```
digger/
  gfx.h          帧缓冲 + 抗锯齿图元
  audio.h        waveOut 实时合成混音器 + 音乐流 + 节拍检测 + MIDI 内置主题
  player.h       Media Foundation 解码、播放列表、顶部工具栏
  sprites.h      全部角色与道具（程序化绘制，没有一张位图）
  level.h        99 关生成器 + 难度曲线
  digger.cpp     游戏逻辑、自适应 AI、渲染编排、HUD、WinMain
  selftest.inc   无头自检
  build.bat
  build/digger.exe   唯一产物：音乐、图标、全部美术都编译在内
```

**没有任何素材文件。** 美术是程序化画的、音乐是代码算的、图标也是用同一套抗锯齿图元
在运行时画出来的（见下）。exe 单独拷走就能跑。

## 编译与运行

```bash
cd C:\dev\digger && build.bat run
```

只编译 `build.bat`，自检 `build.bat test`。把音频文件路径当参数传给 exe 直接进播放列表。

## 三种敌方坦克

敌人是坦克,不是软趴趴的怪物——都有履带、炮塔和炮管,而且**都会开炮**。
车头挂件正好点明各自的本事:

| | 走隧道 | 穿土 | 推金袋 | 开炮 | 车头 |
|---|---|---|---|---|---|
| **Nobbin**（品红） | ✓ | ✗ | ✗ | ✓ | 光炮塔 |
| **Hobbin**（带铲） | ✓ | ✗ | ✓ | ✓ | **推土铲** |
| **Borer**（带钻） | ✓ | **✓** | ✗ | ✓ | **钻头** |

装甲等级仍然是颜色:钢灰(3) → 绿(2) → 橙(1) → 品红(0),车身侧面的装甲条数量对应剩余血量。

## 敌方炮火

**发现即开火。** 没有锁定延迟,也没有"愿不愿意打"的骰子——射界一通,同一帧炮塔就甩上来、
炮口开始起火光。从发现到炮弹出膛**恒定 24 帧(0.4 秒),所有关卡一样**。
炮塔独立于车体转动,所以你会看到炮管先甩过来对准你,车体还在往别处开。

公平性只靠一样东西:**炮口起火光的那 0.4 秒 + 炮弹飞行时间**,必须长于你横移一格所需的时间。
这不是拍脑袋定的数,是自检里算出来的——最坏情况(贴脸开炮)给你 **28 帧**,
而横移一格需要 **22 帧**。所以哪怕零距离,看到火光就让开也躲得掉。

难度不再靠反应迟钝来做,改由射程和射速承担:

- **只沿完全通畅的直线开火**——中间隔着一格土或一袋金子都不打。穿土坦克能钻过泥土,
  但**不能透过泥土射击**。
- **0.4 秒炮口起火光**:炮口发红发亮、炮塔外围转出一圈警示环,然后才出膛。
- **失去射界就丢目标**,不会攒着。已经在起火光的那一发照样打出去,但会打空。
- 炮弹速度 **6px/帧,比你的火球(9px/帧)慢**,同屏最多 3 发,装填最快 1.5 秒。
- **射程 12→20 格**,能顺着整条走廊打过来。你的火球本来就没有射程限制,
  之前给敌人只留 6 格是个莫名的让步。
  而且**远射反而是好躲的那种**:炮弹慢,距离越远飞行时间越长、预警越足——
  11 格外那一发单是飞行就有 81 帧,而你横移一格只要 22 帧。
  真正危险的只有贴脸那一下,而那一档被炮口火光锁死了。
- 吃了樱桃后它们逃跑,**逃跑时不开炮**。
- 金袋能**吸收**敌方炮弹(不会被轰破);只有你的火球才打得开金袋。

### 迎面对消

**你的火球和敌方炮弹迎面相遇会同归于尽**,双双炸掉,加 50 分。
这是游戏里最解气的一手防守:看到炮口起火光,与其躲不如迎着打回去。

实现上有个坑:两者迎面**每帧接近 15px**(火球 9 + 炮弹 6),如果每帧只判定一次碰撞,
它们会**直接穿过彼此**。所以碰撞在**双方各自的 1px 子步里都做判定**。
自检把两者摆在几乎贴面的位置、遍历 15 种相位偏移逐一验证——**15 次全部拦下,没有一次漏穿**。

实测(第 1 关,站在一条被瞄住的通道里):

| 你的应对 | 结果 |
|---|---|
| 站着不动 | **0.8 秒后被击毁** |
| 火光一起就横向让开一格 | **满 60 秒未被命中** |

也就是说火光一定来得及躲,但无视它就会死。

**Borer 是"穿"不是"挖"**：它从实土中直接穿过去，**身后不留任何隧道**，
也不动沿途的翡翠——它不给玩家开路、不改地图，纯粹是一个墙拦不住的威胁。
在土里时用缓存的土层像素半透明盖在它身上，看起来像埋在土中推进，并且有一圈
压力环保证你仍能看清它从哪来（隔墙看不见的敌人是不公平的）。

**但金子挡得住它**：它能穿土，穿不了金属。无论是竖着的金袋还是摔破的金币堆，
都会把它挡在格子外——它推不动金子，也进不了金子所在的格子。

## 坦克推金子

坦克可以把金袋**推进实土**里，金袋一边被推一边替它开路。以前只能把金袋推进
已经挖空的隧道，而金袋大多埋在土里、后面是实土，所以基本推不动；现在无论后面
是土还是空，都推得动，只有另一个金袋或场地边界能挡住。自检里验证了"金袋一开始
确实埋在实土中"以及"坦克把它推穿了实土"。

**炮弹能打破金袋**：一炮打在还没坠落的金袋上，把它当场轰成金币堆(500 分),
不用再费劲把它推到悬空处摔破。自检验证了打破后确实能捡起。

Borer 双重限流：每关总配额 0→5 只，同屏最多 1–2 只。

## 躲炮弹与嘲笑

**三种怪全都会躲**，自检逐种验证过。炮弹在射线上且距离 60–520px 时按概率侧闪一格，
闪避带一次冲刺加速。躲开后**嘲笑你**：四声下行挑衅音效 + 头顶跳动的感叹号。

**每发炮弹只掷一次骰子**（不是每帧掷一次），所以"躲避概率"就是它躲开这一炮的概率。
早先是每帧都掷,一发炮弹飞过来有约 37 次机会,任何非零概率都会饱和成接近 100%,
整条难度曲线形同虚设。

**能力贯穿 99 关持续上升,不封顶**:第 1 关 **28%**,第 99 关 74%。求生是本能而不是
第 40 关才学会的——最早的怪也会躲,只是更容易被算准。这和速度/装甲不同,后两者在
第 71 关就饱和了,**后期变的是更难被算计,而不是更难被追上**。永远不到 100%,
身边没空格时照样中弹。

躲完之后有一段**冷却**:它必须重新往你身上压一段距离才能再躲。没有这个的话,
在你连续开火下它会每一发都侧闪,横着飘一辈子也不过来——那正是"只会躲我"的病根。

实测(同一走廊、两侧都有可闪的通道、玩家不停开火):

| | 第 1 关 | 第 50 关 | 第 99 关 |
|---|---|---|---|
| 主动闪避次数 | 22 | 35 | 36 |
| 被打死次数 | **64** | **36** | **20** |

## 自适应 AI

**怪物的目标是抓住坦克,同时别把自己送死——不是一味躲着坦克。**

追击用的是**真正的寻路**:每帧从玩家所在格向外做一次 BFS,在隧道网络上铺出一张
"走到玩家还要几步"的距离场,怪物只是沿这张场往下坡走。直线距离在迷宫里是没用的
——看起来更近的方向常常是死胡同,贪心的怪会卡在墙上再也不来。会走隧道的
Nobbin / Hobbin 用这张场;Borer 反正无视墙,继续用直线。

在此之上带一个**贯穿整局的玩家模型**(跨关保留,重开清空),持续采样你的习惯:
开炮方向分布、开炮频率、原地不动的比例、横竖移动偏好、以及哪个躲避方向真的活下来了。据此:

1. **提前量拦截**——瞄你速度的前方而不是当前位置,切你的路而不是跟在屁股后面。
2. **别正对炮口硬站**——只在**中远距离(4~15 格)**给"正对你当前朝向那条射线"一点点
   惩罚,让它在两条同样近的进攻路线里挑不正对枪口的那条。这个惩罚被**封顶在一步追击
   价值的一半以下**,而且**近距离(<4 格)完全豁免**——所以它绝不会因此放弃追击,
   最后的扑杀一定会贴上来。
3. **躲飞行中的炮弹**——真正在飞的炮弹靠反应式闪避处理(见上一节),不是靠远远躲开你。
   两边都能闪时,倾向历史上活下来更多的那一侧。

躲避与自适应权重都随关卡从 0 升到满(第 99 关躲避 74%、AI 权重 100),持续上升不封顶。

**效果是实测的。** 自检把一只满级 AI 的怪丢进开阔洞里:

| | 平静时 | 你不停开炮时 |
|---|---|---|
| 它追到离你最近 | **0 格(抓到)** | **2 格** |

也就是说它照样把你追死;开炮只是逼它一路闪着炮弹逼近,而不是把它吓退。

更关键的是**在真实关卡上**测:第 1 关,玩家停在起点不动。巢穴在对角,到起点的
最短隧道距离是 31 格,以怪物速度走完理论上需要 15 秒——实测**首次接触也是 15 秒**,
等于全程零犹豫直奔过来。自检就是拿这个几何下界当基准(允许 1.6 倍余量),这样它
考的是"有没有磨蹭/卡住/跑偏",而不是一个拍脑袋的秒数。另外还验证了
"追击绝不退化成捉迷藏"、以及"走隧道的怪会绕开死胡同"。

**安全阀**:翡翠清空进入 HUNT 模式后,连那点射线回避都砍到 1/4、躲避概率减半——
那时过关只能靠杀光,不留任何理由让它跟你磨蹭。

## 音乐播放器

**常驻顶部工具栏**，不是弹窗，不暂停游戏。上一首/播放暂停/下一首/**洗牌**/打开文件/
播放列表、曲名、时间、进度条、音量、**仿古柱状频谱**、BPM，全部可点可拖。播放列表
是下拉的，点任意一行立刻切歌。`[` `]` 随时切歌，游戏照跑。

**播放顺序**：洗牌按钮切换顺序 / 乱序。顺序模式按歌单从上到下、到底循环；
乱序模式随机跳，且不会连着重复当前这首。

**仿古柱状频谱**：右侧那排是真实的频谱,不是装饰。音频线程里跑了一组 14 个共振
带通滤波器(Chamberlin 状态变量型)对音乐信号实时分频,每个频段做了增益标定
(离散滤波器高频增益会掉,不标定会偏向低音),画成经典图形均衡器那种分段 LED 柱
——底部绿、中间黄、顶部红,每根柱有缓慢下落的峰值标记。自检里喂一个纯音,验证
点亮的正是它音高所在的那一段。

## 默认背景音乐 & 版权

你让我从 archive.org 下载 Hotel California 做默认曲——这一条我没做。那首歌是
Eagles 1976 年的作品,仍在版权期内,archive.org 上的副本基本都是未授权的,
把它下载并打包进游戏分发是明确的侵权。

替代方案:默认背景曲是我**原创的一段芯片音乐**(A小调 Am-F-C-G 进行,方波主音 +
贝斯 + 底鼓 + 踩镲,约 15 秒无缝循环,124 BPM),开机自动播放。它和 MP3 走同一个
混音器,所以频谱和节奏检测都对它生效。你自己下载的任何 MP3(包括 Hotel California)
拖进播放列表就能放——功能在,只是不由我替你去下载受版权保护的文件。

### 主题曲不占播放列表位

这首曲子是**在代码里算出来的**,编译进 exe,不依赖任何外部文件。

而且它**不是播放列表里的一项**——它是"播放列表为空时放的东西"。所以刚打开游戏时
播放列表是**空的**(展开会显示 `PLAYLIST EMPTY - PRESS O TO ADD MUSIC`),但仍然有背景音乐。
你加进来的第一首曲子会接替它;空列表下按上一首/下一首不会变成静音,主题曲继续循环。

这也让"现在放的是不是内置曲"一眼可辨——而变色特效正是靠这个判断来开关的。

**格式支持走 Media Foundation**（Windows 自带，不是第三方库），
mp3 / m4a / aac / wma / flac / wav 都能放，自动重采样和降混到 44.1kHz 单声道。
手写的 RIFF 解码器保留为兜底。工具栏上会显示这一轨走的是哪条路径（`MP3 / MF`、`WAV / RIFF`）。

关键设计：**故意不把文件交给系统去放**，而是自己解码进我们的混音器。
代价是要处理解码；换来的是**样本还在我们手里**——节拍检测分析的是真实信号。

### 节拍与怪物

能量起始点检测：每块算能量，与前 0.5 秒滑动平均比，超过 1.42 倍且距上一拍 >190ms
判定为一拍，再由拍间隔估 BPM。

**放音乐时怪物按节奏行动**：鼓点上猛冲、鼓点间滑行，
有概率在拍点改变方向。硬约束是冲刺速度钳在你的 85% 以内。

### 怪物就是一排会走的频谱柱

**炮管是随音乐动的主角**——它是坦克上视觉最重的部件,音乐挂在那里最跟得住眼睛。
每个部位挂在不同频段上,像工具栏那排柱子一样各自跳:

| 部位 | 频段 |
|---|---|
| 车体悬挂(起伏) | 本体频段 |
| **炮管伸缩 / 后座** | 本体 +2 |
| **炮管偏摆(甩离轴线)** | 本体 +4 |
| 炮塔摇动 | 本体 +6 |
| **炮口辉光** | 本体 +8 |

**不同型号的坦克代表不同音域**,所以一群敌人散在场上就是一条横跨全场的频谱:

- **Borer**(钻头坦克)守低频——第 0~3 段(55~150Hz),重家伙压鼓点
- **Nobbin** 守中频——第 4~8 段
- **Hobbin**(推土铲)骑高频——第 9~13 段

同型号的坦克按出场顺序在自己音域内**再散开**,不会全挤在同一段上。
标题画面那三辆并排的坦克就是这套映射的图例。

没有音乐时自动退回原来的待机动画。

### 放自己的曲子时会变色

**只有放你自己导入的曲目时**才开启——放内置主题曲时坦克保持素色装甲,
这样"这是内置曲"一眼可辨。

车体颜色朝自己频段的代表色偏移,亮度随该频段的音量脉动。频段配色和工具栏那排柱子
同一个阅读顺序:**低频深红 → 琥珀 → 绿 → 青 → 高频紫**。所以低频的钻头坦克会在
鼓点上泛红,高频的推土铲坦克闪蓝紫,一眼能对上频谱柱。

**但装甲读数不能被灯光秀吃掉。** 颜色本来编码装甲等级,是关键战术信息,
所以染色**只动车体色调**——装甲条和头顶的血点用的 `trim` 色**完全不参与染色**,
仍然是纯等级色。逃跑(蓝)和被击中闪白这两个状态也**压过**染色,因为它们是玩法状态。
这三条都有断言守着。

## 图标

窗口/任务栏/Alt-Tab 的图标是**运行时用同一套抗锯齿图元画出来的**,
没有 `.ico` 文件、没有 `.rc` 资源、不需要 rc.exe,也不用两遍编译——
这样才守得住"零素材文件"这条线。

画的是:深色圆角徽章 + 青色坦克(红钻头朝右)+ 下方土层里两颗翡翠。
**16px 那一档另画一版**:去掉土层、宝石和履带链节,坦克放大 1.55 倍居中——
小尺寸塞不下的细节只会糊成一团泥。小图标按 `SM_CXSMICON` 选尺寸,
所以标题栏拿到的是为它那个尺寸画的版本,而不是从大图缩下来的。

自检验证了 16/32/48/64/256 五档都画得出内容、四角透明、中心不透明、alpha 在值域内。

> 一点说明:这样做出来的是**窗口图标**。资源管理器里 exe 文件本身的图标需要嵌入
> `.rc` 资源,那会引入一个 `.ico` 文件和一遍资源编译。你要的话说一声,一行就能加。

## 99 关与难度

按关卡号做种子生成，同关号永远同图。先挖一条从巢穴到起点的**保底主干道**
（Nobbin/Hobbin 不会穿土，连不通整关就废），再叠元胞自动机生成的**有机矿脉**
和随机游走矿脉，最后放金袋（绝不放在主干道上）。

| | 第 1 关 | 第 71 关 | 第 99 关 |
|---|---|---|---|
| 怪物总数 | 5 | 18 | 18 |
| 怪物速度 | 400 | 420 | 420 |
